Build a fully functional FinTech personal finance web app called **“Mizan”**.

### Purpose

Mizan helps users manage their **bills, debts, and savings goals** in one simple and organized place.

### Users

Students, young adults, employees, and families who want an easier way to organize their personal finances.

### Core Features

1. **Authentication**

* Sign Up and Sign In
* Name, email, and password
* Securely store users in MongoDB
* Each user must only see their own financial data
* Use environment variables/secrets for all API keys and database credentials

2. **Dashboard**
   Create a beautiful main dashboard showing:

* Monthly income
* Upcoming bills
* Total remaining debt
* Current savings
* Savings goals progress
* Quick financial summary
* Clear cards and progress indicators
* Helpful alerts for upcoming payments

3. **Bills**
   Users can:

* Add, edit, and delete bills
* Add bill name, amount, due date, and frequency
* Mark bills as paid
* See upcoming and overdue bills
* Receive visual reminders for upcoming bills
* Track monthly recurring subscriptions

4. **Debt**
   Users can:

* Add debts
* Add debt name, total amount, remaining amount, monthly payment, and due date
* Record payments
* Automatically update the remaining balance
* Show debt progress with a progress bar
* Display total remaining debt

5. **Savings Goals**
   Users can:

* Create multiple savings goals
* Add goal name, target amount, current saved amount, and target date
* Add money to a goal
* Automatically calculate the remaining amount
* Calculate approximately how much the user should save each month
* Show progress visually

6. **Navigation**
   Add a clean navigation bar at the **top of every page**:

* Dashboard
* Bills
* Debt
* Savings
* Profile/Settings

Include a clear active-page indicator and a mobile-friendly responsive navigation.

7. **Arabic + English**
   The entire application must support **English and Arabic**.

Add an easy language switcher:
**EN | العربية**

When Arabic is selected:

* Translate all buttons, menus, labels, messages, forms, and dashboard content
* Switch the entire interface to **RTL**
* Make sure Arabic text is properly aligned
* The layout should remain clean and usable in both languages

When English is selected:

* Use **LTR**

Remember the user's language preference.

8. **Light + Dark Mode**
   Add a Light/Dark mode toggle.

Light mode:

* Clean, bright, modern financial dashboard
* White/cream backgrounds
* Soft green/blue accent colors
* Clean cards and subtle shadows

Dark mode:

* Elegant dark background
* Comfortable contrast
* Soft accent colors
* Do NOT use harsh pure black everywhere

Remember the user's theme preference.

### UI/UX Design

Make the design feel like a **modern professional FinTech application**, not a basic student project.

Style:

* Minimal
* Elegant
* Trustworthy
* Modern
* Clean
* Easy to understand
* Spacious layout
* Rounded cards
* Subtle shadows
* Smooth but simple animations
* Clear typography
* Consistent icons
* Excellent spacing and visual hierarchy

The dashboard should immediately show the user's most important financial information without overwhelming them.

Use clear buttons such as:

* Add Bill
* Add Debt
* Create Goal
* Record Payment

Avoid confusing buttons, unnecessary popups, or clutter.

### Database

Use **MongoDB** for persistent storage.

Create appropriate collections/models for:

* Users
* Bills
* Debts
* Savings Goals

Make sure data is associated with the authenticated user and persists after refreshing or reopening the application.

Use the MongoDB connection string from the Replit Secret:
**MONGODB_URI**

Do not hardcode credentials or API keys.

### API Key

I have an API key available in Replit Secrets.

Use environment variables for it and NEVER expose the key in frontend code.

If an AI/API feature is implemented, create a small **Financial Assistant** that can answer questions based only on the user's own financial data, such as:

* “How much do I need to save this month?”
* “What bills are coming up?”
* “How much debt do I have left?”

Do not provide investment recommendations or pretend to be a professional financial advisor.
